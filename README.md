# Task Manager Application GoTo

## Описание функционала

Реализован полноценный менеджер задач с:

- **CRUD-операциями**:
  - Создание, просмотр, редактирование и удаление задач
- **Дополнительными возможностями**:
  - Автоматическое сохранение состояния
  - Адаптивный интерфейс (Mobile/Desktop)
  - Локализация дат и времени

## Инструкция по запуску

### 1. Запуск сервера
cd server
npm install
npm start

### 1. Запуск клиента
cd client
npm install
npm start

Сервер доступен на http://localhost:3001

Технологии
UI фреймворк: Material UI
Бэкенд: REST API, TypeScript
Фронтенд: React, Redux Toolkit, TypeScript
